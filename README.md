# Wellspring Care Platform

Faith-based chaplaincy and ministerial care platform. Next.js + MongoDB Atlas + Stripe + Resend.

## Building with Claude Code
1. Unzip at the repo root, `git init`, commit.
2. First session: `Read docs/progress.md and do the current task.`
3. After each task: `/clear`, then send the same line again.
4. If a session stops on a blocker, read the note in `docs/progress.md`, decide, and reply in that session or the next.

Docs: `CLAUDE.md` (rules), `docs/PRD.md` (requirements, read by section), `docs/PLAN.md` (tasks), `docs/MAP.md` (codebase map), `docs/adr/` (decisions), `docs/content/` (curriculum seed).

Setup, deployment, Stripe and email instructions are written in Phase 9.
